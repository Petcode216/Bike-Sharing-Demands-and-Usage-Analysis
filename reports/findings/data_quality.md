## Decisions

- **Season labels corrected.** The Readme labels `season` 1-4 as spring/summer/fall/winter, but the dates show code 1 spans ~21 Dec-20 Mar (all of Jan and Feb), code 2 ~21 Mar-20 Jun, code 3 ~21 Jun-22 Sep and code 4 ~23 Sep-20 Dec. The codes therefore follow astronomical seasons, and the cleaned data labels them Winter, Spring, Summer and Fall. The original code column is kept.
- `hum = 0` on 2011-03-10 is treated as a sensor error: set to missing in the cleaned humidity columns (rental counts are kept).
- `weathersit = 4` (heavy rain/snow) occurs in only 3 hourly records and never at daily grain; it is merged with category 3 for group statistics and noted as too sparse to analyse on its own.
- No duplicates or count inconsistencies were found, so no rows are removed.
